    Each ported .cs file keeps the upstream copyright header where upstream
    had one, and its namespace line carries a "//was previously:" comment
    naming the upstream namespace.

    Modifications made during the port:
      * Namespaces renamed Tomlyn.* -> CodeBrix.TomlParse.*; the source
        generator's diagnostic IDs renamed TOMLYN001-011 -> TOMLPARSE001-011;
        the NativeAOT feature switch renamed to
        CodeBrix.TomlParse.TomlSerializer.IsReflectionEnabledByDefault and its
        MSBuild property to TomlParseIsReflectionEnabledByDefault.
      * Retargeted to net10.0 only (the generator stays netstandard2.0, as a
        Roslyn component must). Conditional-compilation branches for
        netstandard2.0, net8.0 and older frameworks were resolved to the
        branch that runs on .NET 10, and the netstandard2.0-only polyfill
        files under src/Tomlyn/Compatibility were omitted.
      * Converted to file-scoped namespaces; nullable reference type
        annotations (`?` on reference types and the `!` operator) removed.
      * The source generator emits `#nullable disable` code with no
        reference-type `?` modifiers (upstream emits `#nullable enable`), so
        consumers get no nullable warnings whatever their own setting.
      * Analyzer release tracking files added for the generator's rules.
      * Tests converted from NUnit to xUnit v3 and SilverAssertions; the
        toml-test JSON comparisons were rewritten from Newtonsoft.Json to
        System.Text.Json; the toml-test corpus is read from inside this
        repository (see entry 2) instead of a git submodule.
      * Not ported: the benchmark projects, the NativeAOT smoke-test project,
        the strong-name-signed package project, the documentation site and
        the generated API reference pages.
